# Local fonts

Pirata One (Rodrigo Fuenzalida) and IM FELL English (Igino Marini) were downloaded over verified HTTPS from the Google Fonts repository. They are bundled locally so no Google Fonts network requests are needed. Each font’s SIL Open Font License is retained beside it. These are pirate/letterpress-style fonts, not the official One Piece logo lettering.

- https://github.com/google/fonts/tree/main/ofl/pirataone
- https://github.com/google/fonts/tree/main/ofl/imfellenglish
